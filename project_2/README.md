# Simple Calculator
A command-line calculator built in Python.

## Features
- Addition, subtraction, multiplication, division, modulus, power, square
- Input validation (rejects invalid numbers and choices)
- Divide-by-zero protection
- Calculation history
- Calculate again option

## How to run
```bash
python Simple_calculator.py
```

## What I learned
- Functions and variable scope
- Input validation with try/except
- Using dictionaries to store operator symbols
- Tracking history using a list
