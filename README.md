# Basic Projects
A collection of beginner Python projects built while learning core programming 
concepts — loops, functions, input validation, scope, and error handling.

## Projects

### 1. Number Guessing Game
The computer picks a random number between 1-100, and the player has 
limited attempts to guess it correctly, with "too high/too low" hints.

### 2. Simple Calculator
Performs addition, subtraction, multiplication, division, modulus, power, 
and square, with input validation and calculation history.

### 3. Rock, Paper, Scissors
Play against the computer for a set number of rounds, with live score 
tracking (wins/losses/ties) and a full game history.

### 4. Temperature Converter
Converts between Celsius, Fahrenheit, and Kelvin (6 conversion types), 
with conversion history.

### 5. Mad Libs Generator
Builds a random short story from user-submitted words (adjective, noun, 
verb, place, animal), picking from multiple story templates.

## Common features across all projects
- Input validation using try/except
- Personalized prompts using the player's name
- History tracking for each session
- "Try again?" replay loop

## How to run any project
Open the project folder and run:
```bash
python <filename>.py
```

## What I learned
- Functions and organizing code into reusable pieces
- Variable scope — passing values via parameters and return values
- Input validation with try/except and range checks
- Using lists and dictionaries to track data (history, scores)
- while/else, break, and continue
- f-strings for formatted output
